# Project Registry

This file maps human project names to their canonical GitHub repositories.

Keep one canonical repository per project whenever possible.

| Project | Repository | Start file | Notes |
|---|---|---|---|
| Example Project | `https://github.com/YOUR-USER/example-project` | `START_HERE.md` | Replace this row |
| agent-skills | `https://github.com/YOUR-USER/agent-skills` | `CHATGPT_START_HERE.md` | Bootstrap/reusable agent instructions |

## Rules

- The repository listed here is the source of truth for that project.
- Project-specific state belongs in the project repo, not here.
- Add aliases in the Notes column if a project is commonly referred to by another name.
- If a project is split across multiple repos, list the primary repo first and explain the relationship in that project's `START_HERE.md`.
